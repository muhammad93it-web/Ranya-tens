تۆ دەتوانیت یەک پرۆژەی وێب ئامادە بکەیت بە ناوی "Tennis Ranya" - سیستەمێکی بەڕێوەبردنی مێزەکانی تێنس و یاریگاکانی مێزی یارییە بۆ کوردستان.

## ١. پێکهاتەی گشتی سیستەمەکە:

### الف) ڕووکاری و دیزاین:
- **Theme:** Dark Mode (ڕووکاری تاریک)
- **پاشبنەما:** شینی تاریک یان ڕەساسی تاریک
- **شێوەکان:** گۆشەی چەماو (Rounded corners) بۆ دوگمەکان، کاردەکان، پەنجەرەکان
- **فۆنت:** کوردی (Sorani) - تێکستی تێکەڵا
- **ریسپانسیو:** ئامادە بۆ مۆبایل و ڕایانگە

### ب) سیستەمی ڕەنگ:
- **سەوز (#10B981 یان شبێ):** حاڵەتی ئەرێنی - مێزی بەتاڵ، دوگمەی پەسەندکردن، پاشەکەوتکردن
- **شین (#3B82F6 یان شبێ):** یاریگاکان، لیستەکان، ئاماری خێرا
- **سوور (#EF4444 یان شبێ):** ئاگادارکردنەوە، سڕینەوە، هەڵوەشاندنەوە
- **سپی/خۆڵەمێشی:** تێکست، نووسین (بۆ ڕوونی لەسەر پاشبنەمای تاریک)
- **ڕەساسی تاریک:** پاشبنەما و عنصرەکانی ثانۆی

### ج) پێکهاتەی شاشە:
- **Sidebar لە لای ڕاستی:** مێنیوی سەرەکی بە لیستی ئەم بەشانە
- **ناوەڕۆک:** ناوەڕۆکی سەرەکی بۆ هەر بەشێک
- **Header:** لە سەرەوە - ناوی سیستەمەکە و ئاماری خێرا

## ٢. بەشەکان و فانکشنەکان:

### ١. چوونەژوورەوە (Login)
- دوو رۆل: "ئەدمین" و "کاشێر"
- فۆرمی چوونەژوورەوە بە ناوی بەکارهێنەر و وشەی نهێنی
- سیشن بەڕێوەبردن

### ٢. مێزەکان (Dashboard)
- **شاشەی سەرەکی:** گرید (Grid) یان لیست بە کاردەکان بۆ هەر مێز
- **لە سەرەوە:** ئاماری خێرا:
  - کۆی پارە (Total Money) بە دینار عێراقی (د.ع)
  - ژمارەی مێزەکانی کە وەستاون (Idle tables count)
- **لە هەر کاردە:** 
  - ناوی مێز
  - حاڵەتی مێز: "بەتاڵ" بە ڕەنگی سەوز یان "گیراو" بە کاتی سەردەمی و نرخی هاوچەرخ
  - دوگمەی دەستپێکردنی کات (Start Timer)
- **فانکشنەکان:**
  - کلیک کردن بۆ دەستپێکردنی کات بۆ مێزێک
  - کاتیمەر خۆکاری - هەژماری کات و نرخ
  - کۆتایی پێهێنان و پاشەکەوتکردنی داتا

### ٣. کاتیەکان (Times)
- دوگمەکانی کاتی پێشوەختە: 60 خولەک، 30 خولەک، 15 خولەک
- بەکاردێت بۆ خێرایی دیاریکردنی کات بۆ مێزێک

### ٤. بەڕێوەبردنی مێزەکان (Manage Courts)
- **بۆ ئەدمین تەنها**
- **فانکشنەکان:**
  - **زیادکردن:** فۆرمی زیادکردنی مێزی نوێ (ناو، نرخی هۆرلی)
  - **لیست:** تابلۆی هەموو مێزەکان
  - **دەستکاری:** ناو و نرخ دەستکاری بکە
  - **سڕینەوە:** سڕینەوە بە دوگمەی سوور

### ٥. ڕاپۆرتەکان (Reports)
- **ئاماری خێرا:**
  - کۆی داهات (Total Income)
  - کۆی خەرجی (Total Expenses)
  - قازانجی پوختە (Net Profit)
- **تابلۆی تێکراو:**
  - هەموو یارییەکانی تێپەڕوو
  - ستونەکان: بەروار، مێز، کات، نرخ
  - فلتەرکردن بە بەروار

### ٦. خەرجییەکان (Expenses)
- **فۆرمی زیادکردن:**
  - جۆری خەرجی (Expense Type) - dropdown یا text
  - بڕی پارە (Amount) - بە دینار عێراقی (د.ع)
  - بەروار (Date) - خۆکاری ئەمڕۆ
  - دوگمەی پاشەکەوتکردن
- **لیستی خەرجییەکان:**
  - تابلۆ یا لیست بە هەموو خەرجییەکان
  - ستونەکان: بەروار، جۆر، بڕ
  - دوگمەی سڕینەوە بۆ هەر خەرجیێک

### ٧. بەکارهێنەران (Users)
- **بۆ ئەدمین تەنها**
- **فانکشنەکان:**
  - **زیادکردن:** فۆرمی زیادکردنی بەکارهێنەری نوێ
    - ناوی بەکارهێنەر (Username)
    - وشەی نهێنی (Password)
    - رۆل (Role): ئەدمین یا کاشێر
  - **لیست:** تابلۆی هەموو بەکارهێنەران
  - **دەستکاری:** رۆل و وشەی نهێنی
  - **سڕینەوە:** سڕینەوە بە دوگمەی سوور

### ٨. ڕێکخستنەکان (Settings)
- **بۆ ئەدمین تەنها**
- **فانکشنەکان:**
  - **ناوی سیستەمەکە:** دەستکاری ناو (بۆ نموونە: "Tennis Ranya - Erbil")
  - **ڕەنگی ڕووکاری:** هەندێک ڕەنگی جیاواز بۆ هەڵبژاردن (Dark Blue, Dark Gray, Dark Purple)
  - **باکئەپ و ڕیستۆری:**
    - دوگمەی "Backup" - دانلۆد کردنی داتا
    - دوگمەی "Restore" - بارکردنی داتای پاشەکەوتکراو
  - **بەستنە بە پلاتفۆرمەکان:**
    - Telegram API Key - بۆ ناردنی ئاگادارینامە
    - Discord Webhook URL - بۆ ناردنی ئاگادارینامە

## ٣. تایبەتمەندیەکانی تەکنیکی:

### الف) بنچینەی داتا:
- **مێزەکان:** ID، ناو، نرخی هۆرلی، حاڵەت
- **یارییەکان:** ID، مێزی ID، کاتی دەستپێ، کاتی کۆتایی، نرخی کۆ
- **خەرجییەکان:** ID، جۆر، بڕ، بەروار
- **بەکارهێنەران:** ID، ناوی بەکارهێنەر، وشەی نهێنی (هاشکراو)، رۆل

### ب) فانکشنەکانی پشتەوە:
- **کاتیمەر:** خۆکاری هەژماری کات و نرخ
- **هەژماری:** خۆکاری هەژماری نرخ بۆ هەر مێز
- **ڕاپۆرتەکان:** کۆکردنی داتا و دروستکردنی ڕاپۆرتەکان
- **سیشن:** بەڕێوەبردنی چوونەژوورەوە و دەسەڵات

### ج) یاریدەدەری:
- React یا Vue.js بۆ Frontend
- Node.js/Express یا Python/Flask بۆ Backend
- MongoDB یا PostgreSQL بۆ Database
- Tailwind CSS بۆ styling
- Responsive Design بۆ مۆبایل و ڕایانگە

## ٤. ڕۆژنامەی کاری:

**بەشی ١:** بنچینەی پڕۆژە و ڕووکاری سەرەکی
**بەشی ٢:** شاشەی مێزەکان (Dashboard) و کاتیمەر
**بەشی ٣:** کاتیەکان و بەڕێوەبردنی مێزەکان
**بەشی ٤:** ڕاپۆرتەکان و خەرجییەکان
**بەشی ٥:** بەکارهێنەران، ڕێکخستنەکان و چوونەژوورەوە
**بەشی ٦:** تێستکردن و بەتێکاری
